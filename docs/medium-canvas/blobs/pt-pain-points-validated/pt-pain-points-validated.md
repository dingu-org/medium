# PT pain points (validated)

**No-shows:** ~20% rate, emotionally charged, PTs manage with policies not tech. Current reminders help but aren't enough.

**Admin burden:** 91% link to burnout, 35% of workday. **But: PTs most excited about AI for documentation, not scheduling.**

**Communication fragmentation:** Real (one strong Jane App review asking for WhatsApp integration) but not top-tier complaint.

**Multi-location scheduling:** Validated pain for mobile PTs working across cities.

**Tech adoption:** PTs are slow adopters - need obvious ROI.
