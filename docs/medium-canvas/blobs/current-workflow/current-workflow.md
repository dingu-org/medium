# Current workflow

**First-time patients:** Need to specify reason for appointment so therapist can confirm they provide that service. Then select from available slots by date and location.

**Recurring patients:** Usually book next appointment in-person at end of session. Therapist adds these manually.

**Scheduling complexity:** Therapist works across two cities on different days, so availability varies by location. Some days only available in one city.

**Changes:** Client or therapist-initiated changes require manual contact and schedule updates, sometimes triggering cascade of notifications to offer freed slots to other clients.
