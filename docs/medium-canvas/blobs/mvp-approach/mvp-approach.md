# MVP approach

**PWA for PT:** Calendar view showing appointments. Each appointment shows chat history with that client. PT can chat directly or let AI handle.

**Client experience:** Client messages PT's business WhatsApp/Instagram. AI handles conversation autonomously, books appointment when agreed, notifies PT. PT can see everything in PWA and intervene when needed.

No integration with existing PT software initially. Focus on making the AI + multi-channel messaging work first.
