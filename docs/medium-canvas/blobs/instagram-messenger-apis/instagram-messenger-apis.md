# Instagram & Messenger APIs

**Both free** (no Meta fees unlike WhatsApp). AI autonomous responses allowed.

**Instagram:** Works for booking conversations within 24-hour window. **Cannot send automated reminders** after window closes. Still valuable as differentiator - no competitor offers Instagram.

**Messenger:** Works for booking and reminders. Message tags being deprecated April 27, 2026 - must use Marketing Messages API (paid, opt-in) for reminders.

Can use same Meta Business account as WhatsApp. 2-4 weeks development per channel.
